# Character Codegrees of VZ and Camina p-groups

This repository contains the following preprint, along with the related data and code:

Ayush Udeep, Character Codegrees of VZ and Camina p-groups.

The name of the file of the preprint is PapercodegreeVZ.pdf.

The code is designed for use with Magma.

Each directory Table-J where J \in {1,...,3} encodes data recorded in the corresponding table of the paper.
